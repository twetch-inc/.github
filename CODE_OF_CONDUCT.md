# Code of Conduct

This covers our repositories — issues, pull requests, discussions and reviews.
It is not the moderation policy for the Twetch network itself, which is a
different thing with different rules.

## The short version

Be decent to the people you're working with. Argue about the code, not the
person writing it.

## In practice

- **Critique the work.** "This drops a signature check" is useful. "Did you even read the spec" is not.
- **Assume the other person is trying.** Most bad code is someone solving a problem you can't see yet.
- **Take the correction.** Being wrong in a pull request costs nothing. Defending it costs everyone time.
- **No harassment.** Personal attacks, sustained pile-ons, sexual attention, or dragging someone's identity into a technical thread are all out.
- **Don't post other people's private information.** Ever, for any reason.
- **Don't weaponize the repos.** Issues aren't for grudges from elsewhere.

## Scope

This applies anywhere you're representing these projects — repositories,
review threads, and any space where you're acting on their behalf.

## Enforcement

Report problems by DM to [**@twetchapp**](https://x.com/twetchapp) on X. Tell us
what happened and where; include links if you have them. We'll look into it and
we won't share your name with the person you reported.

Depending on what we find, we may edit or remove the content, ask for an
apology, or block the account from the organization's repositories. Repeated or
severe behaviour skips straight to the last one.

We'd rather resolve something with a quiet word than a ban, and usually do.
